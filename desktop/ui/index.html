Send your show from BUTT or Mixxx to this app, as if it were an Icecast server. When the sound arrives, the studio goes live for you (if your slot allows it); when you stop, the show ends and the AutoDJ takes over.

Setting up BUTT
  1. In BUTT, open Settings → Main → Server → Add.
  2. Type Icecast, address 127.0.0.1, the port and password above, mount live, user source.
  3. Under Audio, pick codec MP3, 44100 Hz, stereo, 128 kbps or more.
  4. Press Play in BUTT when it’s your time.

Using BUTT’s Shoutcast type instead? Give it the port above minus 1 (): Shoutcast sends its sound to the next port up.

Setting up Mixxx
  1. In Mixxx, open Options → Preferences → Live Broadcasting.
  2. Type Icecast 2, host 127.0.0.1, the port above, mount /live, login source, the password above.
  3. Encoding MP3, 128 kbps or more, stereo.
  4. Turn on Enable Live Broadcasting when it’s your time.
